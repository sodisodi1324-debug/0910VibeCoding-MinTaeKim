# 0910VibeCoding-MinTaeKim

개인 소개를 위한 한 페이지 웹사이트 (Next.js + TypeScript + Tailwind CSS).

## 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인.

## 데이터 수정

`data/profile.json` 파일에서 이름, 소개 글, 관심사, 링크를 수정할 수 있습니다.
